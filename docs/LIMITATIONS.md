# OZPanorama Beta — known limitations

- **Tested on one rig only**: three 27" 16:9 monitors (curved 1500R center), NVIDIA, Windows 11. Ultrawide, 4K, mixed monitors, AMD and Windows 10 have not been tested.
- **Not tested on other computers yet**: until there are testers, other Documents folders (OneDrive, another drive) are not confirmed.
- **MSFS 2024**: you must first create the two extra windows in the simulator (one per monitor, full screen). The app does not create windows or change monitor numbers; it asks which window is on the left. MSFS uses the same FOV in every window, so the outer edges of the side screens keep a small perspective error. The recommended zoom has to be set by hand in developer mode. MSFS 2020 is not supported.
- **ETS2 / ATS**: need Surround (or Eyefinity) turned on. The app does **not** change the game resolution; if it differs from the Surround area, it warns you and you choose it in the game options.
- **iRacing**: only accepts three equal monitors and the same angle on both sides. The 7 keys must already exist in `rendererDX11Monitor.ini` (iRacing creates it on first run).
- **RaceRoom**: needs Surround (or Eyefinity) and the game at the full Surround resolution. Tested with Surround bezel correction on (bezels written as 0); without it, the bezel values are not yet tested. The game rewrites `graphics_options.xml` when it exits, so close it before applying. The eye height is not written yet (it stays as set in the game).
- **Assetto Corsa**: needs Surround (or Eyefinity) and three screens with the same resolution (the game splits the image into three equal parts). Tested with Content Manager and Custom Shaders Patch. Close the game before applying. The game resolution is not written: choose the Surround resolution in Content Manager. If you change the video settings in Content Manager afterwards, keep the screen mode on Triple, and do not save the triple screen page of the original launcher (it overwrites the positions).
- **Le Mans Ultimate (experimental)**: `Config_DX11.ini` is in the game's Steam folder (`UserData`). The width and gap written are fitted to the game's own screen model (equal thirds with hidden Surround pixels), not the physical values; this model is not yet confirmed on a rig. The game resolution is not written: if the game was opened with Surround off it may save a single-screen resolution and turn off Multiview; choose the Surround resolution in the game's graphics settings with Surround on. Seat Pitch (seat tilt) different from 0 misaligns the side screens. The game process name used to block applying while it is open is not yet confirmed.
- **Assetto Corsa Competizione**: not in this Beta.
- **NVIDIA Surround on/off**: uses profiles saved by the NVIDIA driver itself (you save them once). After switching, the app asks you to confirm and puts back the previous setup after 20 s without an answer. Tested on the author's rig only; AMD Eyefinity is not supported.
- **Monitor detection (EDID)**: sizes come in whole millimetres or centimetres, and on a curved monitor it is usually the chord. With Surround on, monitors are read from the Windows registry; old entries of the same monitor are merged, but a monitor you no longer use may still be listed. A tape measure is more accurate.
- **Unsigned executable**: SmartScreen and some antivirus programs may warn (see README).
- **Window**: opens in its own window using the Microsoft WebView2 Runtime (part of Windows 10/11). Without WebView2 it falls back to Microsoft Edge app mode, and without Edge to the default browser.
